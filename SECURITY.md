# Security policy

This is a personal portfolio project, but I take reports seriously.

## Reporting a vulnerability

Please use GitHub's private reporting: open the Security tab of this repository and choose "Report a vulnerability". Please do not post details in a public issue.

Helpful things to include: the URL or request, what you did, what you expected and what happened. I will reply as soon as I can. This is a one-person project, so there is no fixed response time.

## Scope

In scope: the live site at https://explain-this-cve.vercel.app and the code in this repository.

Out of scope: the third-party services it reads from (NVD, CISA, FIRST EPSS, the AI provider) and Vercel's platform. Please do not run load tests or automated scanners against the live site. It runs on a free plan, and the data sources it uses have shared quotas.

## What is already known

The README lists the known limitations, for example per-instance rate limits and the free-tier AI quota. Reports about those are welcome but already documented.
